# Rebel Production House (RPH)

> Stories That Challenge. Voices That Matter.

Rebel Production House (RPH) is a digital media and content platform focused on original, meaningful, and engaging stories.

The platform brings together podcasts, films, journalism, social documentaries, motivational content, interviews, and stories that inspire change under one brand identity.

The website is designed to provide an immersive and cinematic experience inspired by modern media platforms while maintaining a unique RPH identity.

---

## 🎯 Project Vision

RPH aims to create a digital media platform where powerful stories, diverse voices, and meaningful content can be discovered and experienced in one place.

The experience is intended to combine:

- Cinematic visual storytelling
- Original media content
- Podcasts and interviews
- Films and documentaries
- Journalism and social stories
- Motivational and thought-provoking content
- A modern and immersive user experience

## 🎨 Brand Identity

RPH follows a premium, cinematic visual identity.

### Color Palette

| Color | Hex Code | Purpose |

| Dark Brown | `#2B1D16` | Brand accent and backgrounds |
| Matte Black | `#0F0F0F` | Primary background |
| Royal Gold | `#C8A95B` | Highlights, buttons, and accents |
| Ivory | `#F5F1E8` | Primary text and light elements |

The visual language should feel:

- Premium
- Cinematic
- Bold
- Minimal
